Universal Jet Checklist (FSX Default Aircraft)
This checklist is designed to work with all default FSX jets (737, 747, A321) using full realism settings.

1. PRE-FLIGHT & STARTUP

Parking Brake: SET

Battery & Avionics: ON

Fuel Quantity: CHECKED

Throttles: IDLE

Engine Start: ENGAGE (Ctrl+E or GND switch)

Generators: ON (after stable N2)

Pitot Heat: ON (Anti-ice for probes)

2. BEFORE TAKEOFF

Flight Director: ON

Auto-Throttle: ARM

Flaps: SET for Takeoff (5 or 10)

Speed (IAS): SET 250 kts

Altitude: SET initial clearance

Heading: SET runway heading

Transponder: NORM / TA/RA

Landing Lights: ON

3. CLIMB & CRUISE

Landing Gear: RETRACT (Positive rate)

Autopilot: ENGAGE (CMD A)

Flaps: RETRACT (on schedule)

Altimeter: SYNC (Press 'B' at Transition Altitude)

10,000 ft: Landing Lights OFF / Increase Speed

4. DESCENT & APPROACH

Altimeter: SYNC to Destination Local Pressure

Auto-Brake: SET (1, 2, or 3)

Speed: REDUCE to 210 kts

NAV1 Radio: TUNED to ILS Frequency

Course (CRS): SET to Runway Heading

Spoilers: ARM (Shift + /)

Landing Lights: ON (below 10,000 ft)

5. FINAL LANDING

Approach Mode (APR): ARM at GS/LOC intercept

Landing Gear: DOWN

Flaps: FULL (30 or 40)

Landing Speed: Vref + Gust Factor (approx. 145-155 kts)

Autopilot/A-Throttle: DISCONNECT (at 500 ft or earlier)

Throttles: IDLE (at flare/touchdown)

Thrust Reversers: ENGAGE (Hold F2)

6. AFTER LANDING

Flaps: RETRACT

Spoilers: RETRACT

Auto-Brake: OFF

Lights: Strobe OFF / Taxi ON
